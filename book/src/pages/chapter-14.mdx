# Chapter 14: Visualization Options

The visual presentation of the scanning highlight plays a critical role in user accuracy and visual fatigue.

The primary goal of visual highlighting is to make the active target **unambiguous** from an operational distance (1–2 meters) without introducing visual clutter or distracting screen motion (Thistle & Wilkinson, 2015).

## Visual Highlighting Parameters

- **Outline Border Width:** Thick high-contrast borders vs thin minimalist lines.
- **Background Color Shift:** Inverting cell colors or applying high-contrast focus hues (e.g., bright yellow/cyan on dark slate).
- **Scale Elevation (Zoom Factor):** Elevating the active target slightly (1.1× to 1.2× scale) to create 3D depth separation.
- **Opacity Dimming:** Dimming non-active background items to 40–50% opacity to draw visual focus exclusively to the active scan step.
- **Scan Line Sweeps:** A moving progress line sweeping across the active cell to indicate remaining dwell/scan time.

## Design Guidelines by User Need

- **Low Vision / Cortical Visual Impairment (CVI):** Use thick high-contrast borders (6–8px), bright solid fill highlights, and high-contrast symbol backgrounds. Avoid subtle pastel color shifts.
- **High Cognitive Load / Seizure Sensitivity:** Use static border highlights without scale animations or pulsing motion. Keep screen brightness uniform.
- **Advanced / High-Speed Users:** Minimal visual highlighting (thin 2px borders), no zoom animations, allowing fast visual tracking across dense grids.
