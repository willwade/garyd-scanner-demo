# Chapter 19: Error Recovery

Errors in single-switch scanning carry an immense time penalty. In linear or row-column scanning, correcting a single mistaken selection requires locating and selecting a "Backspace" or "Undo" item, costing an additional **15–45 seconds** of scan steps (Venkatagiri, 1999).

Without accessible, low-cost error recovery mechanisms, users experience severe frustration and frequently abandon scanning systems entirely.

<div class="warning-box">
  <strong>The Error Penalty:</strong> A single uncorrected error invalidates preceding work. If error recovery requires navigating back through 3 menu layers, a single mistake destroys net communication speed.
</div>

## Four Essential Error Recovery Mechanisms

### 1. Empty Item Resets
Selectable dummy cells placed strategically in scan groups that immediately abort the active scan cycle without producing output or sending text. Allows the user to "safely miss" or intentionally reset a wrong row selection.

### 2. Long-Hold Emergency Cancel
Encodes a long-press gesture (e.g., holding the switch continuously for 1000 ms) to immediately cancel the active scan cycle and return to the main home page from anywhere in the interface.

### 3. Dedicated Backspace & Undo Targets
Placing Backspace, Undo, and Clear buttons in high-priority scan positions (e.g., Row 1 or Column 1) ensures immediate access when a mistaken character is committed.

### 4. Automatic Level Escape (Timeout Reset)
If a user selects a row or pop-up menu but makes no further switch press for 2 complete scan cycles, the software automatically escapes back to the top-level home page.
