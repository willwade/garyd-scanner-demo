# Chapter 24: UX Design Patterns & Best Practices

Designing software for switch scanning requires a shift from spatial visual layout to **temporal interaction design**. 

This chapter synthesizes essential UX design patterns for building fast, intuitive, and low-fatigue scanning applications.

## Recommended Design Patterns

### 1. Progressive Disclosure
Show a small set of primary core targets first (e.g., core vocabulary words, Yes/No, top actions). Provide explicit link items to expand into secondary categories only when needed.

### 2. Frequency-Weighted Ordering (ETAOIN SHRDLU)
Place high-frequency letters, common phrases, and critical actions in early scan positions (Row 1, Column 1). Ordering by frequency cuts average scan distance per selection by up to 45%.

### 3. Context-Aware Dynamic Grids
Automatically adapt selection grids based on active task context. When text entry is active, present letters and word prediction; when media playback is active, present Play, Pause, and Volume controls.

### 4. Predictive Candidate Placement
Position word prediction candidate boxes directly above or adjacent to the letter keyboard so the scan line moves fluidly from letter input into candidate selection.

### 5. Deterministic Navigation & Safe Defaults
Keep scan ordering completely predictable. Avoid dynamic spatial reorganization during an active scan sequence, as unexpected target shifts break motor timing and cause misselections.

<div class="highlight-box">
  <strong>Golden Rule of Scanning UX:</strong> Consistency builds muscle memory and speed. Never change target locations during a scan cycle without explicit user navigation.
</div>
